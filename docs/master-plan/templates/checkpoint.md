# Task checkpoint

- Project/task/slice:
- UTC timestamp / journal sequence:
- Provider / CLI / exact session ID:
- Requested and resolved model / effort:
- Worktree / branch / base SHA / current SHA:
- Plan/task/decision version hashes:
- Current state and reason:
- Owned files; dirty files belonging to others:
- Verified outcomes (evidence IDs, exact code/schema):
- Changed behavior and invariant reasoning summary:
- Failed/not-run checks and blocker:
- External action intents with unknown outcome (operation ID; no secrets):
- Uncommitted diff/patch artifact hash:
- Required decisions/permissions still pending:
- Observed quota window/reset/source, or unknown:
- Exact next bounded action and expected result:
- Rollback/recovery point:

Keep concise. Link large logs and source files instead of copying them. Do not store credentials, customer records, raw provider tokens or private chain-of-thought. A checkpoint is evidence of known state, not permission to repeat an uncertain mutation.
