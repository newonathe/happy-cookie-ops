# MP-08m — local Pages session route composition

Status: local composition complete, 2026-09-24; G1 remains in progress. This slice joins the accepted MP-08b handler, MP-08k authority, MP-08c Auth transport, MP-08d crypto, and MP-08j SQL repository at the Pages Function boundary. It does not change the locked UI/UX or claim a hosted or physical-device release.

## Files and ownership

1. Add `spikes/pages/functions/lib/service-rpc.ts` and `tests/unit/pages-service-rpc.test.ts`. The module is reachable only from the Pages Function tree. It uses a fixed allowlist of the seven BFF RPCs plus `consume_rate_limit`, generated `Database` argument/return types, an injected `fetch`, and a configured HTTPS Supabase origin. It sends a new `sb_secret_*` key only as `apikey`; an explicitly identified legacy service-role JWT sends both `apikey` and bearer headers for the pinned local fixture only. It never copies request Authorization or cookies. It sets `cache: no-store`, forbids redirects, passes the authority's AbortSignal, bounds response bytes, rejects malformed or unexpected responses, and returns only a static error marker to the authority. No error body or key is logged.
2. Add `spikes/pages/functions/lib/session-composition.ts` and focused tests. Require an exact configured `APP_ORIGIN` (HTTPS outside loopback), `SUPABASE_URL`, `SUPABASE_PUBLISHABLE_KEY`, `SUPABASE_SERVICE_KEY`, explicit `SUPABASE_SERVICE_KEY_KIND`, and `SESSION_CRYPTO_CONFIG_JSON` from Pages bindings/secrets. The service key and encryption material are never included in the static export or response. Construct one request-scoped authority. Use `CF-Connecting-IP` only when Cloudflare's incoming `request.cf` metadata exists; local emulator testing uses a fixed, non-request-derived `HCO_LOCAL_TRUSTED_CALLER_ID` on a loopback origin only. Never use `X-Forwarded-For` or a client-supplied role. Rate rules are session 60/60 seconds, login 10/900 seconds, refresh 12/60 seconds and logout 12/60 seconds; the handler's fixed `Retry-After: 60` is only a retry hint for the longer login window. A missing or invalid binding returns a fixed non-cacheable 503.
3. Change only `spikes/pages/functions/api/[[path]].ts` and its focused test. Preserve GET/HEAD liveness and fixed 503 for other APIs. Dispatch only four exact session paths to `handleSessionRequest`, using configured origin and request-scoped authority. Pass the adapter's `deferRecovery` to Pages `context.waitUntil`; no fire-and-forget promise. Keep Function-owned no-store/security headers on every path.
4. Extend the command-line Wrangler emulator test with unconfigured-session failure and unchanged health/sync/static checks. Use injected fake Auth/RPC in unit tests to prove cookie/CSRF/role/expiry, rate failure, missing configuration, spoofed forwarding headers, response privacy, abort and recovery scheduling. A real isolated PostgREST + GoTrue integration run is a separate acceptance requirement before MP-08 or MP-04 can close.
