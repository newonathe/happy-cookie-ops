# MP-08c — server-only Supabase Auth transport

Status: local implementation and verification complete; not wired into SessionAuthority or deployed.

Implement a small injected Fetch adapter for password exchange, refresh, user lookup and device-local logout. Claude Sonnet/medium owns only src/lib/auth/supabase-auth-transport.ts; root owns independent tests and integration. No children or concurrent duplicate implementation. This is authorized local G1 work; locked UI, migrations, credentials, hosted accounts and persistent session storage are outside scope.

Configuration is a trusted canonical HTTPS origin and publishable key. No environment reads or service-role key. Require sb_publishable_ prefix (legacy JWT keys deliberately unsupported here). Fixed /auth/v1 paths, redirect:error, cache:no-store, caller AbortSignal, no retries. Validate bounded credential/token inputs before fetch. Read decoded JSON bodies through the existing bounded reader, projected to exact output fields, maximum64KiB. Widen its input structurally to Pick<Request,'headers'|'body'|'bodyUsed'> so Response bodies can reuse the same reader; omit upstream wire content-length/content-encoding when adapting Fetch-decoded responses. Validate JSON content type. All raw network/provider/parse errors become one static AuthTransportError('auth_dependency_unavailable'); provider denial is null only for exact expected status/code pairs. Logout succeeds only on204 and explicitly scope=local. No claim that JWTs are immediately revoked.

Acceptance: independent injected Fetch tests using real Request/Response/ReadableStream cover fixed URL/method/headers, exact outputs, credential non-leakage, error classification, redirect/cache/signal, malformed/oversized bodies, preabort and no retries; pnpm verify plus independent security review. Caller owns total deadline and persistent authority, atomic refresh/revocation, active profile authorization and uncertain commit handling. Transport is not authentication acceptance. Docker-blocked MP06k SQL remains pending.
