This is only a size check: no policy was enforced or browser-tested in that receipt.

## Local implementation and acceptance

1. Post-process the exact emitted HTML into a deterministic static `_headers` CSP with `script-src 'self'` plus SHA-256 hashes of every inline script. No `unsafe-inline` for scripts. Preserve `style-src 'self' 'unsafe-inline'` because the locked design uses inline styles. Reject missing/malformed output, executable inline event handlers, missing hashes or any header line over Cloudflare's 2,000-character limit. Hashes must be regenerated on each build, never copied from a previous artifact.
2. Keep static security headers and safe cache behavior: HTML revalidates; only fingerprinted `/_next/static/*` gets immutable browser caching. Function/Worker-generated API responses keep their own no-store and security headers because `_headers` applies only to static assets. Test actual local response headers and CSP behavior in headless CLI checks; do not change visual output.
3. Add a Workers static-assets config and minimal API entry point over the same export. Locally prove the identical health/method/session/sync/static/404 oracle under Workerd and confirm no secret or local `.env` is required. Do not claim private-file, bounded-sync or hosted Auth acceptance from a 503 fixture.
4. Run the pinned full `pnpm verify`, both local adapter oracles, a dry-run bundle, integrity/continuity checks and an evidence-index refresh. Mark only this local prerequisite complete if those checks pass. Keep the known offline E2E failures and MP-06/07/08 parent gaps visible.

Root owns the Workers comparator, final integration and status evidence. One bounded Codex Luna/medium worker owns only the Pages CSP/build/oracle files, with root review. No Claude or paid fallback. The implementation stays outside protected UI/engine paths and below the repository's 400-line slice boundary per writer.
